# Analysis Packages

This directory contains the empirical analysis families in the repository.

## `interrupted_time_series/`

Active descriptive empirical strategy. This is the place to read first for the
current paper-ready project-entry result and for future publication,
comparative-exposure, and returned-data analyses.

The ITS family is descriptive. It documents recorded project-start and output
trajectories around institutional dates; none of the modules should be read as
automatically causal designs.

## `did_archive/`

Archived earlier causal/comparative DID attempts and exploratory outputs. These
files are retained for provenance, diagnostics, and historical comparison only.
They are not the current main empirical design.
