# Intermediate Data

This folder keeps transition and audit outputs that are useful for
reproducibility but are not the first place to look for the main regression
results.

- `stage2_universe/`: public UKB project/publication universe construction.
- `start_date_matching/`: recovered UKB project start-date matching outputs.
- `timing_feasibility/`: timing-feasibility counts and fixed working universe.
- `rap_classification/`: provisional RAP exposure classification outputs.
- `control_expansion/`: C0-C6 control-candidate expansion review files.
- `fast_pipeline/`: earlier fast Stage 4/5 checkpoint outputs.

Use `data/analysis/` for current design panels and regression tables.
